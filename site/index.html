Your codebase, mapped —
and an agent that can read the map.

Blacksite is an AI coding agent for VS Code with deep workspace integration: LSP-backed code intelligence, durable multi-phase plans, an embedded data workbench, and a rendered star-field of your repository that the agent queries with the same tools you navigate.

What's in it

Codebase Map

Files are stars, imports are arcs, services are territories. Built from a real index with per-language import resolution across TypeScript, Go, Java, C#, Python, PHP, and Rust.

An agent that queries it

Impact analysis, path finding, and neighborhood lookup are tools the agent can call. It reasons about the same graph you're looking at, not a separate flattened copy.

Service lens

Detects API providers and verified HTTP clients, event pub/sub, and data access across roughly ten frameworks — so cross-service edges reflect calls that actually exist.

Code intelligence

Symbols, navigation, type hierarchies, diagnostics, rename, and code actions through VS Code's own language servers. The agent uses your real toolchain, not a guess at it.

Durable plans

Multi-phase plans with per-step state that survive session boundaries, so long-horizon work can be picked up where it stopped instead of restarted.

Reviewed edits

Every file change is previewed and approved before it touches disk, with post-edit diagnostics fed straight back to the agent.

Data workbench

An embedded SQLite workbench with a query editor, table preview, and vector search, plus an optional pgvector sidecar.

Your provider, your key

Anthropic, OpenAI, OpenRouter, or AWS Bedrock. Requests go from your machine to your provider. There is no Blacksite server in the path.

Install

Requires VS Code 1.85 or newer and an API key for one supported provider.

Download the latest .vsix from Releases, then: 

code --install-extension blacksite-vscode-<version>.vsix

Or in VS Code: Extensions → … → Install from VSIX…

Then run Blacksite: Set API Key from the command palette and pick your provider. Keys go into VS Code's SecretStorage, never into settings files.

Blacksite checks for updates on startup and can install them in place. Turn that off with blacksite.updates.checkOnStartup if you'd rather manage versions yourself.
